# 🎓 Edusity University – Modern University Landing Page

A modern, fully responsive university landing page built with **React** and **Vite**. The site showcases the university's programs, campus life, gallery, testimonials, and contact information. Designed to attract prospective students with a clean, professional, and engaging interface.

🌐 **Live Demo**: [dernounimk.github.io/edusity-university-demo](https://dernounimk.github.io/edusity-university-demo/)

---

## ✨ Key Features

- **Hero Section** – "The better education for a better world" with a vibrant campus description.
- **What We Offer** – Overview of academic programs and opportunities.
- **About University** – Detailed section on nurturing tomorrow's leaders, with focus on innovation, hands-on learning, and mentorship.
- **Gallery Section** – Campus photos (placeholder for images).
- **Testimonials** – Student reviews (Liza Rodri, Lucas Alba, Sia Fernandez, Toni Rose).
- **Contact Section** – Contact form, email, phone, and address (Algeria, Batna).
- **Fully Responsive** – Optimized for all devices (desktop, tablet, mobile).
- **High Performance** – Built with Vite for fast loading and Hot Module Replacement (HMR).
- **Clean Code** – ESLint configuration for consistent code quality.
